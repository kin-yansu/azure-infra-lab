# ADR-001 バックエンドにFastAPIを採用する

## ステータス

承認済み

## コンテキスト・文脈・背景

ADR-000のBicepトレーニングに続き、インフラ上で動作するバックエンドを構成する。
今後、デプロイスワップと環境変数の動作を確認するため、まずローカルで起動できるAPIを用意する。

## 決定

- バックエンドはPythonのFastAPIで実装し、`backend`ディレクトリで管理する。
- ASGIサーバーにはUvicornを使用する。
- `GET /health`でプロセスの稼働を確認できるようにする。
- `GET /`はサービス名と`APP_ENV`の値を返す。未設定時は`local`とする。
- `GET /environment`で環境変数をかえす'
- `/docs`でOpenAPI仕様を確認できるようにする。
- Azure App Serviceをコンテナを使用する。コンテナはACRにプッシュする。
- 検証用なのでパブリックアクセスを許可する。

## 結果・影響

- インフラとバックエンドを同じリポジトリで管理できる。
- `/docs`でAPI仕様を確認できる。
- ヘルスチェックは外部サービスへの接続確認を含まない。
- 環境変数の公開は`APP_ENV`に限定し、認証情報などはレスポンスに含めない。
